# 0.1.0 initial release

Working Windows desktop release: database/book opponents, historical-player repertoire filtering, legal SVG board, source labeling, streaming catalog, Polyglot explorer, game replay/variations, saves/PGN export, optional UCI analysis and hybrid fallback. Six source-format routes plus archive-book extraction tested.

Delivery classification: PARTIAL against the full mission. Core playable acceptance is verified. This initial release does not establish million-game performance, broad external database compatibility, full-game batch evaluation, tournament-filtered opponents, advanced clocks, clean-machine/DPI matrices or production readiness. Proprietary and Scid formats are recognized but unsupported. See README for exact limits.
